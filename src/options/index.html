KeenSwitch settings

Two steps: connect to the router, then say which device to switch.

1. Router

Sign-in details for the Keenetic web interface.

The same address you use to open the Keenetic panel.

The password is stored in plain text chrome.storage.local is readable by anyone with access to your Chrome profile. The password is sent only to the address you specified, and only as a hash (SHA-256 of the challenge).

2. My device

This is the device whose policy will be switched.
